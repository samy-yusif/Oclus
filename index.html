About the sample data (read this)
  • 118 activities, 8 WBS groups, FS/SS logic with lags, delivery constraints (start-on-or-after), 7-day calendar. NTP 01-Jul-2025, data date 28-Sep-2026.
  • Durations, crews, slips and dates are invented for demonstration. They are not from a real project and not a benchmark.
  • Machine positions, haul routes and crane stations are illustrative, not a lift or logistics plan. 1 crew dot ≈ 6 workers.
  • On the Quest, switching Ghost off lowers the triangle count (the not-yet-built plant is no longer drawn).
  • Download XER writes this schedule as a P6 XER file (generated in your browser). It follows the published XER table layout but has not been tested by importing into P6.
  • Import XER reads TASK dates by Activity ID. Only IDs that match the sample codes (e.g. CIV110, MEC210) move the model; this is the link table you would rebuild for a real project.
How to open this on the Quest 3
  1. WebXR needs an https:// address: drag this file (renamed index.html) onto app.netlify.com/drop, or publish it with GitHub Pages.
  2. On the Quest 3 open the Browser, go to the link, press Enter AR, allow the prompts, put the controllers down for hand tracking.
